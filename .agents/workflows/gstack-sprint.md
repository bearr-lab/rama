# GStack Sprint

**Description**: Run the complete GStack sprint methodology on a new feature or idea.

**Steps**:
1. **Office Hours**: Ask the user to describe the feature or problem they want to solve. Run the `@office-hours` skill to refine the scope and create a design doc.
2. **Build**: Once the design doc is approved, implement the code changes required to build the feature. Wait for the user to confirm they are ready for review.
3. **Review**: Run the `@review` skill to act as a Staff Engineer and review the changes you just made.
4. **QA**: Run the `@qa` skill to test the feature and ensure no regressions were introduced.
5. **Ship**: Summarize the completed work, list the tests that were added or modified, and inform the user the sprint is complete!
